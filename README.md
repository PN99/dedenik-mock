# Dedeník a Svět Dede

Původní HTML mockup je v `index.html`. WordPress šablona je v `wordpress/dedenik`; nyní verze 0.3.1 včetně správy Světa Dede a nové patičky. Toto je existující repozitář PN99/dedenik-mock, rozšířený o skutečnou šablonu.

Repozitář neobsahuje databázi, původní WordPress jádro, knihovnu médií, konfiguraci hostingu ani přístupová hesla.

- [Správa Světa Dede, Podcastů a Divadla](wordpress/dedenik/SPRAVA-SVETA-DEDE.md)
- [Správa patičky](wordpress/dedenik/SPRAVA-PATICKY.md)
- [Autodeploy na testovací subdoménu](wordpress/AUTODEPLOY.md)

Lokální vytvoření instalačního ZIPu: `python wordpress/package-theme.py`.
