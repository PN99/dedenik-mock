# Dedeník a Svět Dede

Původní HTML mockup je v `index.html`. WordPress šablona je v `wp-content/themes/dedenik`. Toto je existující repozitář PN99/dedenik-mock, rozšířený o skutečnou šablonu.

Kořen repozitáře obsahuje WordPress. Databáze, knihovna médií, konfigurace hostingu a přístupové údaje se spravují mimo Git. Vývoj, test a vydání popisuje [návod pro přispěvatele](AGENTS.md).

- [Správa Světa Dede, Podcastů a Divadla](wp-content/themes/dedenik/SPRAVA-SVETA-DEDE.md)
- [Správa patičky](wp-content/themes/dedenik/SPRAVA-PATICKY.md)
- [Autodeploy na testovací subdoménu](wordpress/AUTODEPLOY.md)

Lokální vytvoření instalačního ZIPu: `python wordpress/package-theme.py`.
